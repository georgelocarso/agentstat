⚡ Detailed Technical Analysis

Edge Case Warning: Auto-Unarchive on Page Refresh

In packages/web/src/hooks/useSSE.ts, when the initial snapshot arrives from the daemon, every session active within the last 60 minutes is passed to onAutoUnarchive(sessionId). If a user intentionally archives a recently active session and refreshes their browser, that session is immediately unarchived.

Recommended Fix for Auto-Unarchive

// packages/web/src/hooks/useSSE.ts
// Rather than checking raw elapsed time since lastSeenAt:
const prevState = previousStateMap.current.get(snapshot.sessionId);

// Only trigger auto-unarchive on an actual transition back to active work:
if (
  prevState &&
  prevState !== 'working' &&
  prevState !== 'waiting_approval' &&
  (snapshot.state === 'working' || snapshot.state === 'waiting_approval')
) {
  onAutoUnarchive?.(snapshot.sessionId);
}
